# Derma Delight Design System (Preliminary)

## Identity
Elegant, welcoming, premium Kenyan beauty brand with distinct adult, kids and beard-care collections.

## Palette
| Token | Value | Usage |
| --- | --- | --- |
| Ivory | #F8F1E9 | Page backgrounds |
| Rose gold | #D8A17E | Accent |
| Chocolate | #553225 | Primary text and CTA |
| Kids pink | #F5B4C9 | Kids collection |
| Beard taupe | #85715F | Beard Care collection |
| White | #FFFFFF | Product surfaces |

## Typography
- Headlines: Playfair Display
- Body and interface: DM Sans

## UI principles
- Editorial full-width hero, not a generic split-screen marketplace template
- Generous whitespace and refined typography
- Consistent cards, buttons, spacing and accessible contrast
- Mobile-first navigation and usable touch targets
- Adults: champagne, copper and ivory; Kids: pink, peach and cream; Beard Care: warm taupe, charcoal and bronze

## Product photography
- One realistic product per catalogue image
- Plain clean background, consistent studio lighting and scale
- **Use the supplied official logo asset; do not regenerate or approximate the logo.**
- Current CSS bottle illustrations are temporary placeholders, not final product photos or verified packaging.

## Accessibility
Semantic landmarks, descriptive button labels, visible keyboard focus, sensible headings and responsive layouts. Perform keyboard and screen-reader testing before release.
