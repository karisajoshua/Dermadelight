# Derma Delight

Premium skincare and kids' haircare storefront for Kenya.

**Brand:** Derma Delight — Science for Radiant Skin  
**Website (planned):** https://dermadelight.co.ke  
**Contact:** info@dermadelight.co.ke · +254 720 815 270 · Ruiru, Kenya

## Status

Preliminary frontend scaffold. This is a **single-store** application. No Barakaz source code has been copied yet; reuse will be evaluated after the current Barakaz repository is confirmed.

## Run locally

```bash
npm install
npm run dev
```

Requires Node.js 20+. Run `npm run build` before deployment.

## Included

- React + TypeScript + Vite storefront
- Responsive header and mobile navigation
- Adults and Kids collections
- Six provisional catalogue entries
- Local shopping-cart state (browser storage only)
- Product detail modal and quantity management
- Editorial homepage sections and brand story

## Not yet implemented

- Live product inventory and approved prices
- Supabase database, authentication and row-level security
- Secure checkout and payment verification
- Admin dashboard and order management
- Real product photos and official logo assets
- Shipping rates and delivery service integration

Do not collect payments or real customer orders until a production backend and payment provider are configured.
